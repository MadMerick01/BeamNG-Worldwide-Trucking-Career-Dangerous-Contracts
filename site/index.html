How to join

  1. Install BeamNG.drive and BeamMP, and sign in to BeamMP. Signed-in players keep their career on any PC.
  2. Download the BeamNG.Earth app, the same version as the server (the newest one), and keep it running while you play.
  3. In the BeamMP server browser, open the BeamNG.Earth tab and join Trucking Career Test | MadMerick. The trucking mod downloads by itself.
  4. First time only: press Esc, go to System > HUD Apps > .Earth (edit layout) > + Add app, pick BeamNG Worldwide Trucking Career: Dangerous Contracts, then + Add to layout and Save. Type !hud in chat to see this again.

Your money and trucks are kept on the server, separate from single player. Press Save in the HUD to keep your progress. Want the mod for single player? Get it from the latest release.
